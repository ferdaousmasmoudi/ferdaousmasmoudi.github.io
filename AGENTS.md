# AGENTS

## Goal
Build a professional, jury-facing personal website using al-folio.

## Constraints
- Keep the al-folio structure; do not rewrite the theme.
- Prefer minimal changes; edit config/pages/content only.
- Light mode, clean, futuristic-minimal aesthetic.
- Home page must act as a jury landing page: fast to scan, strong visual hierarchy.
- All external links must be visible and clickable (CV PDF, Thesis PDF, Research profiles).
- Use short sections and strong CTA buttons.
- Language: French UI. Technical terms can stay in English when needed.

## Must-have pages
- / (jury landing)
- /cv/ (PDF + quick highlights)
- /thesis/ (PDF + abstract + keywords)
- /publications/ (BibTeX based if possible)
- /projects/ (cards with images)
- /code/ (GitHub repos + Simulink/Matlab assets)

## Assets
- PDFs in assets/pdf/
- Images in assets/img/
